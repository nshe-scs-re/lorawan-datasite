This repo contains all related code for a senior project.

## UI draft

The `src/ui` folder contains the LoRaWAN-TCC welcome page for now. The navigation
buttons for pages have not been built yet.

## View the UI locally

Install Node.js (which includes npm), then from the repository root run:
`cd src/ui && npm ci && npm run dev`

Open the local address printed by Vite (usually http://localhost:5173) in
browser to see the page. The dev server keeps running while viewing the UI, so,
press `Ctrl+C` in the terminal to stop it.
